- Backend complete end-to-end; ads + subscription monetization designed

### 🏆 HPE CDS Tech Challenge 25/26
**🥇 1st nationally · 🥉 3rd globally · Madrid 🇪🇸**

Real-time digital twin of Aruba's police, ambulance, fire, civil protection
and drone fleets.

- Telemetry, island events and weather streamed over **Kafka**
- Live dispatch dashboard with dynamic ETAs and OSRM routing
- LLM assistant + historical replay of any past incident window

Built with <a href="https://52sec.org">52Sec</a>
